# My Oh My - XAVA Token Dashboard 🚀

A beautiful, modern, real-time dashboard for the XAVA token with stunning visuals and live data updates.

## ✨ Features

- **Real-time Price Updates**: Live price tracking with 3-second refresh intervals
- **Beautiful Charts**: Interactive price history charts with gradient fills
- **Live Transactions**: Real-time transaction feed with buy/sell indicators
- **Token Statistics**: Comprehensive stats including market cap, volume, holders, and supply
- **Modern UI**: Gradient backgrounds, smooth animations, and responsive design
- **Auto-refresh**: Automatic data updates without manual refresh

## 🎨 Design Highlights

- **Gradient Background**: Beautiful animated gradient background
- **Glass Morphism**: Cards with backdrop blur and transparency effects
- **Smooth Animations**: Framer Motion animations for all interactions
- **Color-coded Data**: Green for positive changes, red for negative
- **Live Indicators**: Pulsing live indicator to show real-time status
- **Responsive Layout**: Works perfectly on desktop, tablet, and mobile

## 🛠 Tech Stack

- **Next.js 15**: React framework with App Router
- **TypeScript**: Type-safe development
- **Tailwind CSS**: Utility-first CSS framework
- **Framer Motion**: Smooth animations and transitions
- **Recharts**: Beautiful and responsive charts
- **React Query**: Data fetching and caching
- **Lucide React**: Beautiful icons
